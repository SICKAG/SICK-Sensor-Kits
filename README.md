# SICK Sensor Starter Kits

This repository contains both:

- The source for the [documentation website](https://sickag.github.io/SICK-Sensor-Starter-Kits/)  
- The full source code, example projects and community contributions

## Structure

- `docs/` – Documentation source (MkDocs, English/German)  
- `projects/` – Official SICK example projects  
- `community/` – Community and university project submissions  
- `contributing/` – Guidelines and templates for contributing
