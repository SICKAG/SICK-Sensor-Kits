# Contributing

Thank you for your interest in contributing to the SICK Sensor Starter Kits.

Universities, students, educators, developers and community members are welcome to submit projects created with the:

- Vision Starter Kit
- LiDAR Starter Kit
- IO-Link Connectivity Starter Kit

This section provides the resources required to prepare and submit a community project.

## Contribution Resources

### How to Submit a Project

The submission guide explains the complete process, including:

- copying the project template
- preparing the project files
- completing the project metadata
- creating a Git branch
- opening a Pull Request
- responding to review feedback

how-to-submit-a-project.md

### Community Project Guidelines

The guidelines describe the general requirements for submitted projects, including:

- documentation quality
- project structure
- source code quality
- testing
- security
- sensitive information
- third-party content and licenses

community_project_guidelines.md

### Project Template

Use the provided project template as the starting point for every submission.

project_template/

The template contains:

```text
project_template/
├── README.md
├── project-info.yml
├── requirements.txt
├── src/
└── images/
```

Do not create a different project structure unless it is required for the project and discussed with the maintainers.

## Basic Contribution Process

The general process is:

```text
Copy the project template
        |
        v
Add project files and information
        |
        v
Test the project
        |
        v
Create a Pull Request
        |
        v
Project review
        |
        v
Approval and merge
```

After a project has been reviewed and merged, the SICK team may manually add it to the GitHub.io project overview.

A submitted project does not automatically create a GitHub.io page.

## Repository Responsibilities

Community contributors provide:

- project information
- source code
- images
- required configuration files
- dependencies
- a complete project README
- tested and reproducible instructions

The SICK team is responsible for:

- reviewing the submission
- requesting changes where necessary
- approving and merging accepted projects
- maintaining the visual project overview on GitHub.io
- adding links from GitHub.io to accepted community projects

## Before Contributing

Before starting a submission:

1. Read the Community Project Guidelines.
2. Review the project template.
3. Read the project submission guide.
4. Use GitHub Discussions if the project idea or process is still unclear.

## Need Help?

Use GitHub Discussions for:

- questions about the contribution process
- feedback on an early project idea
- help with the project template
- general Starter Kit questions

Use GitHub Issues for:

- reproducible repository problems
- errors in the project template
- errors in the contribution documentation
