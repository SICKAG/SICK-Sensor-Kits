# Contributing

Thank you for your interest in contributing to the SICK Sensor Starter Kits.

Contributions from universities, students, educators, developers and community members are welcome.

You can contribute by:

- submitting a community project
- reporting a bug
- suggesting an improvement
- proposing a new project idea
- participating in GitHub Discussions

## Submit a Community Project

Community projects must be based on one of the following:

- Vision Starter Kit
- LiDAR Starter Kit
- IO-Link Connectivity Starter Kit

Before submitting a project, use the provided template and read the complete submission guide:

- community/contributing/how-to-submit-a-project.md
- community/contributing/project_template/

The submission guide explains how to:

- prepare the project structure
- add code, images and project information
- complete `project-info.yml`
- test the project
- create a branch
- submit a Pull Request
- respond to review feedback

Accepted community projects are added to this repository after review.

The SICK team may then manually add the project to the GitHub.io project overview and link it to the corresponding project folder in this repository.

## Report a Bug

Use GitHub Issues to report reproducible problems with:

- source code
- downloadable files
- project instructions
- repository structure
- project templates

https://github.com/SICKAG/SICK-Sensor-Starter-Kits/issues

Please use the appropriate Issue template and provide as much relevant information as possible.

## Ask a Question or Share an Idea

Use GitHub Discussions for:

- general questions
- help with a Starter Kit project
- early project ideas
- feedback before submitting a project
- community exchange
- sharing completed projects

https://github.com/SICKAG/SICK-Sensor-Starter-Kits/discussions

Questions should normally be posted in Discussions rather than submitted as Issues.

## Pull Requests

All project contributions and repository changes should be submitted through a Pull Request.

Before opening a Pull Request:

- use a separate branch
- review the changed files
- test the project or modification
- remove credentials and confidential information
- complete the Pull Request template

The SICK team reviews each contribution and may request changes before approval.

## Documentation

The guided Starter Kit documentation, setup instructions and project overviews are available on GitHub.io:

https://sickag.github.io/SICK-Sensor-Starter-Kits/en/

This repository primarily contains source code, project files, downloads and community contributions.
