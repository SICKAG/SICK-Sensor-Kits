FAQ - Vision Starter Kit

Here you will find answers to frequently asked questions about the Vision Starter Kit.

For general questions about the Starter Kits, please visit the general FAQ section.

The device is running slowly, how can I improve this?

In the Acquisition section, you can adjust the "Downsample" slider to reduce the image resolution and increase the processing speed.
It is important to do this at the beginning of a project as all created regions (e.g. for Object Locator or AI tools) are not adjusted accordingly.

Where can I get more information about all the tools?

Within Nova, you can directly get more information about every tool by accessing the "Help" section (Screenshot).
You can also find a comprehensive overview about all tools here: SICK Nova documentation (COMING SOON)

How can I use the data from SICK Nova in an IDE (e.g. Visual Studio or Python)

Use the "Results" section in Nova on the left to send the data or use one of the Code Snippets
