# LiDAR Training Material

## Short Description

This page collects additional training resources for the LiDAR Starter Kit.

At the moment, no dedicated LiDAR training material is available on this page.  
Use the recommended learning path and related documentation pages below to get started with the LiDAR Starter Kit.

## Recommended Learning Path

If you are new to the LiDAR Starter Kit, follow this order:

<div class="strategy-grid">

  <div class="strategy-card">
    <h3>1. Complete Getting Started</h3>
    <p>Connect the LiDAR sensor, configure the network adapter and open the sensor user interface.</p>
  </div>

  <div class="strategy-card">
    <h3>2. Run the First Demo</h3>
    <p>Start with the Field Evaluation project to understand how detection fields work.</p>
  </div>

  <div class="strategy-card">
    <h3>3. Explore Example Projects</h3>
    <p>Continue with distance estimation, interactive games or audio-based LiDAR applications.</p>
  </div>

  <div class="strategy-card">
    <h3>4. Continue with Code Examples</h3>
    <p>Use the LiDAR code examples to read device information, scan data or field evaluation results with Python.</p>
  </div>
