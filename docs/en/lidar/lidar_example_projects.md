# Example Projects LiDAR Starter Kit

Explore example projects for the LiDAR Starter Kit.  
The projects are grouped by type, difficulty and estimated duration to help you choose the right starting point.

You can follow guided projects step by step, use showcase projects as inspiration or try challenge projects to build your own solution.

-   ![Field Evaluation](../images/lidar.jpg)

    **Field Evaluation**

    **Type:** <span class="project-badge guided">Guided Project</span>  
    **Difficulty:** Basic  
    **Estimated duration:** 10 to 30 minutes  
    **Requirements:** Test objects  

    Draw detection fields and test how different objects infringe these fields.

-  ![Distance Estimation](../images/distance_estimation.png)

    **Distance Estimation**

    **Type:** <span class="project-badge challenge">Challenge Project</span>  
    **Difficulty:** Basic  
    **Estimated duration:** 1 to 2 hours  
    **Requirements:** Any objects  

    Estimate the distance to an object and learn how LiDAR measurement data can be used for distance-based applications.

    [Distance Estimation](distance_estimation.md){ .md-button }

-   ![Lava](../images/lava.jpg)

    **The Floor is Lava**

    **Type:** <span class="project-badge guided">Guided Project</span>  
    **Difficulty:** Basic  
    **Estimated duration:** 20 to 40 minutes  
    **Requirements:** Several people or objects  

    Play "The Floor is Lava" with a LiDAR scanner that detects infringed fields.

    [Floor is lava](lidar_floor_is_lava.md){ .md-button }

-   ![Piano](../images/piano.jpg)

    **Human Piano / Air Piano**

    **Type:** <span class="project-badge showcase">Showcase Project</span> 
    **Difficulty:** Advanced  
    **Estimated duration:** 30 to 60 minutes  
    **Requirements:** Several people or objects, audio output or external application  

    Create multiple detection fields and use a basic Python application to play sounds based on field infringements.

    [Human air piano](lidar_human_piano_air_piano.md){ .md-button }

## Recommended First Project

If you are new to the LiDAR Starter Kit, start with the [Field evaluation](lidar_field_evaluation.md) project.  
It introduces the basic concept of detection fields and is a good first practical demo after completing the Getting Started guide.
