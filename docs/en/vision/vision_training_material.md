Use these materials if you want to deepen your understanding of SICK Nova, image acquisition, AI-based classification and practical machine vision workflows.

## Practice-Oriented Learning

The best way to learn the Vision Starter Kit is to work through example projects.

Start with a guided project and then continue with challenge or advanced projects.

Recommended order:

1. Vision Starter Project
2. Classify Hex Nuts / Screws
3. Sketch Demonstrator
4. Recycling
5. Advanced projects such as Black Jack, UNO or Rock, Paper, Scissors

!!! info 
    This order gradually increases the complexity from basic image acquisition to AI Classification and application logic.
