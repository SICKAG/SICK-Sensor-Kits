## Short Description

This showcase project demonstrates how different AI and non-AI tools in SICK Nova can be used for a quality inspection task.

By following the SICK Nova tutorial series, you will learn how to inspect a chocolate bar and understand how similar inspection workflows can be transferred to other objects or packaged goods.

## What This Project Demonstrates

This project shows how a visual inspection workflow can be created with the Vision Starter Kit and SICK Nova.

You will see how different tools can be combined to inspect an object, evaluate visual characteristics and understand typical quality inspection workflows.

This showcase can help you understand:

- how image-based inspection tasks can be structured
- how AI and non-AI tools can support visual inspection
- how a tutorial-based project can be adapted to your own object
- how the InspectorP61x from the Vision Starter Kit can be used instead of the sensor shown in the video

---

Set up the Vision Starter Kit as described in the [Getting started](./vision_getting_started.md) guide.

## How to Follow Along

This project is intended as a showcase project.  
Instead of following a full written step-by-step guide on this page, follow the individual steps in the tutorial videos.

While following the videos, keep the following adaptation in mind:

1. Use the **InspectorP61x** from the Vision Starter Kit.
2. Use a chocolate bar, the recommended 3D printed object or another packed grocery item.
3. Recreate the shown inspection workflow in SICK Nova.
4. Test whether the workflow can detect or evaluate the relevant object characteristics.
5. Adjust acquisition, tool settings and inspection logic if necessary.

!!! tip "Adapt the project"
    If you do not have the exact same chocolate bar or object, use a similar packed grocery item.  
    The goal is to understand the inspection workflow, not to reproduce the tutorial object exactly.
