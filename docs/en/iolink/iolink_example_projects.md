
# Example Projects IO-Link Connectivity Starter Kit

Explore example projects for the IO-Link Connectivity Starter Kit.  
The projects are grouped by type, difficulty and estimated duration to help you choose the right starting point.

You can follow guided projects step by step, use showcase projects as inspiration or try advanced projects to combine multiple sensors and additional hardware.

## Recommended First Project

If you are new to the IO-Link Connectivity Starter Kit, start with the [SensorFusion](sensor_fusion.md) project.

The project allows you to try the included sensors, compare their sensing technologies and visualize their digital outputs using LEDs.
