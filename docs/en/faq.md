# FAQ

## Short Description

This FAQ page answers general questions about the SICK Sensor Starter Kit documentation, support resources and additional learning material.

For questions related to a specific Starter Kit, please check the FAQ page of the corresponding kit.

---

## General Questions

??? question "Where can I find support articles?"

    You can find support articles and technical information in the [SICK Knowledge Base](https://support.sick.com/knowledgebase/)

---

??? question "Where can I find product information?"

    Product information, downloads, manuals and technical data are available on [sick.com](https://www.sick.com/products).

---

??? question "Is there a video tutorial channel?"

    Yes. The SICK Sensors YouTube channel provides videos, tutorials and product-related content.

    [Youtube](https://www.youtube.com/watch?v=9dk3b6dBXlw){:target="_blank" .md-button .button-small}

---

??? question "Where can I find the documentation for a specific Starter Kit?"

    Use the navigation on the left side to select the corresponding Starter Kit.

    The documentation is organized by Starter Kit:

    - Vision Starter Kit
    - LiDAR Starter Kit
    - IO-Link Connectivity Starter Kit

---

??? question "Where can I find complete project files and source code?"

    The GitHub.io documentation provides explanations, setup guides and project overviews.

    Complete project files and source code should be provided through the [GitHub.com](https://github.com/SICKAG/SICK-Sensor-Starter-Kits){:target="_blank"} project repository.



---

??? question "Is the documentation available in multiple languages?"

    Yes. The documentation is structured into separate English and German versions.

    You can switch the language by using the language selector in the header.

---

??? question "Where can I find additional training material?"

    Training material is linked in the corresponding Starter Kit section.

    For Vision, additional learning resources can be found here:

    [Training Material](vision/vision_training_material.md){ .md-button .button-small}

---
