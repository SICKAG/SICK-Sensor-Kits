## What problem needs to be solved?
Incorrectly sorted waste objects shall be detected automatically to support recycling and waste separation processes.
OR: detect foreign waste in a bin (e.g. plastics in a box of paper).

Project ideas:

* Immediate display of foreign object
* Visual display as result of the inspection (green / red light)
* Challenge the system with more difficult materials / forms

## What needs to be clarified and prepared in order to offer this use case?
Definition of object classes
