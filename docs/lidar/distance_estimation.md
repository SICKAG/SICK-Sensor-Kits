## What problem needs to be solved?
Human distance estimation and spatial memory shall be evaluated using 3D sensor data in a playful setup.

Project ideas:

* Accurate distance measurement with 3D sensor
* Game dashboard that generates a given distance value by chance
* Deviation analysis and dashboard
