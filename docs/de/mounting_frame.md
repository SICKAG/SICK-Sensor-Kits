# Einrichtung des Montagerahmens

Auf dieser Seite wird erklärt, wie der Befestigungsrahmen für die SICK-Sensor-Starter-Kits zusammengebaut wird.

Der Befestigungsrahmen bietet eine stabile und verstellbare Halterung zur Positionierung des Sensors bei Vorführungen, Schulungen und Beispielprojekten.

!!! info "Bevor Sie beginnen"
    Vergewissern Sie sich vor Beginn der Montage, dass alle erforderlichen Teile vorhanden sind.  
    Der Rahmen wird als gemeinsame Komponente für mehrere Starter-Kits verwendet.

## Montageschritte

Befolgen Sie die folgenden Schritte, um den Montagerahmen zusammenzubauen.

---

## Schritt 1: Die obere Leiste vorbereiten

Verwenden Sie ein Aluminiumprofil als obere Leiste des Befestigungsrahmens.

1. Nehmen Sie ein Aluminiumprofil aus dem Karton.
2. Setzen Sie eine **M4-T-Nut-Mutter** in die obere Nut ein.
3. Setzen Sie zwei **M5-T-Nut-Muttern** in die untere Nut auf der gegenüberliegenden Seite der M4-Mutter ein.
4. Befestigen Sie zwei Winkelhalterungen mit Senkkopfschrauben.
5. Ziehen Sie die Schrauben mit dem 3-mm-Inbusschlüssel in den M5-T-Nut-Muttern fest.
6. Setzen Sie an beiden Enden des Profils Endkappen auf.
7. Schieben Sie die Winkelhalterungen an beide Enden des Profils und ziehen Sie die Schrauben so fest, dass die Winkelhalterungen und die Endkappen fluchten.

!!! tip "Montagehinweis"
    Stellen Sie sicher, dass die M4-T-Nut-Mutter an der Oberseite zugänglich bleibt. Sie wird später zur Befestigung der Sensorhalterung benötigt.

---

## Schritt 2: Die unteren Leisten vorbereiten

Verwenden Sie zwei Aluminiumprofile als unteren Rahmenstreben.

1. Setzen Sie jeweils eine **M5-T-Nut-Mutter** in die mittlere Nut jeder unteren Leiste ein.
2. Befestigen Sie jeweils eine Winkelhalterung mit Senkkopfschrauben an jeder unteren Leiste.
3. Ziehen Sie die Schrauben mit dem 3-mm-Inbusschlüssel fest.
4. Setzen Sie an beiden Enden jeder unteren Leiste Endkappen auf.
5. Legen Sie beide Profile parallel vor sich hin.

Die Profile sollten der Länge nach ausgerichtet sein, sodass die Enden einmal zu Ihnen hin und einmal von Ihnen weg zeigen, nicht seitlich über den Tisch hinweg.

---

## Schritt 3: Befestigen Sie die vertikalen Stangen

Verwenden Sie zwei Aluminiumprofile als vertikale Stangen.

1. Setzen Sie am unteren Ende jeder vertikalen Stange eine **M5-T-Nut-Mutter** ein.
2. Befestigen Sie jede vertikale Stange im 90°-Winkel an einer der unteren Stangen.
3. Verwenden Sie eine Senkschraube und den 3-mm-Inbusschlüssel, um die Verbindung festzuziehen.
4. Setzen Sie am oberen Ende jeder vertikalen Stange eine **M5-T-Nut-Mutter** in die Nut ein, die zur anderen unteren Stange zeigt.
5. Setzen Sie auf jeden vertikalen Stab eine Endkappe auf.

!!! tip "Montagehinweis"
    Es ist möglicherweise einfacher, den Rahmen flach hinzulegen, während man die obere Leiste anbringt.

---

## Schritt 4: Die obere Leiste montieren

Befestigen Sie die obere Leiste mit den beiden verbleibenden Senkkopfschrauben zwischen den beiden vertikalen Leisten.

1. Positionieren Sie die obere Leiste zwischen den vertikalen Leisten.
2. Richten Sie die Winkelhalterungen an den T-Nut-Muttern in den vertikalen Stangen aus.
3. Ziehen Sie die Schrauben mit dem 3-mm-Inbusschlüssel fest.
4. Passen Sie bei Bedarf die Höhe und den Winkel der oberen Leiste an.
5. Lösen und ziehen Sie die inneren Schrauben oben an den vertikalen Stangen fest, um die Position genau einzustellen.

---

## Schritt 5: Befestigen Sie die Sensorhalterung

Befestigen Sie die InspectorP61x-Halterung mit der mitgelieferten M4-Schraube und Unterlegscheibe.

1. Setzen Sie die Halterung über die M4-T-Nut-Mutter an der oberen Leiste.
2. Setzen Sie die mitgelieferte M4-Schraube mit Unterlegscheibe ein.
3. Ziehen Sie die Schraube vorsichtig fest.
4. Stellen Sie sicher, dass die Halterung fest sitzt.

---

## Erwartetes Ergebnis

Nach Abschluss der Montage sollte der Befestigungsrahmen stabil stehen und eine einstellbare Befestigungsposition für den Sensor bieten.

Der Rahmen ist nun bereit für den Einsatz mit dem Starter-Kit.
