# Übersicht über das LiDAR-Starter-Kit
Das LiDAR-Starter-Kit bietet eine Einführung in die Arbeit mit LiDAR-Sensoren. Es enthält Tools, Dokumentation und Beispiele, die Ihnen den schnellen Einstieg erleichtern.

Sie haben noch kein LiDAR-Starter-Kit? Hier können Sie es kaufen!

[Starter-Sets](https://www.sick.com/ag/en/catalog/products/training/training-and-education/technology-trainings/lidar-starter-kit-basics/p/p687690?tab=detail){:target="_blank".md-button}

![LiDAR-Starter-Kit](../images/lidar.jpg)

## Wichtigste Merkmale
- Hochpräzise Entfernungsmessung
- Einfache Konfiguration mit SOPASair
- Einfache Integration in verschiedene Anwendungen
