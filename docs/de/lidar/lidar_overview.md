# Übersicht über das LiDAR-Starter-Kit

Willkommen bei der Dokumentation zum **LiDAR-Starter-Kit**.

Das LiDAR-Starter-Kit unterstützt Sie beim Einstieg in die Entfernungsmessung, die Feldauswertung und interaktive LiDAR-basierte Anwendungen. Es umfasst einen picoScan150-LiDAR-Sensor, Zubehör, Dokumentation sowie Beispielprojekte für Schulungs- und Demonstrationszwecke.

![Lidar](../images/lidar.jpg){ width="650" }

## Wichtigste Merkmale

- Hochpräzise Abstandsmessung
- Feldversuch zur Objekt- und Flächenerkennung
- Einfache Konfiguration mit SOPASair
- Einfache Integration in interaktive Anwendungen
- Beispielprojekte für schnelles Lernen durch praktische Übungen

## Was kann man damit machen?

Mit dem LiDAR-Starter-Kit können Sie typische LiDAR-Anwendungen erkunden, wie zum Beispiel:

- Entfernungsmessung
- Feldauswertung
- Objekterkennung in festgelegten Bereichen
- interaktive Spiele und Vorführungen
- Szenarien mit sensorbasierter Auslösung und Rückmeldung
