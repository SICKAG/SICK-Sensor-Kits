# Schulungsmaterial zu LiDAR

## Kurzbeschreibung

Auf dieser Seite finden Sie weitere Schulungsmaterialien zum LiDAR-Starter-Kit.

Derzeit sind auf dieser Seite keine speziellen Schulungsunterlagen zum Thema LiDAR verfügbar.  
Nutzen Sie den empfohlenen Lernpfad und die unten aufgeführten Dokumentationsseiten, um mit dem LiDAR-Starter-Kit loszulegen.

## Empfohlener Lernpfad

Wenn Sie das LiDAR-Starter-Kit zum ersten Mal verwenden, gehen Sie bitte wie folgt vor:

<div class="strategy-grid">

  <div class="strategy-card">
    <h3>1. Erste Schritte abschließen</h3>
    <p>Schließen Sie den LiDAR-Sensor an, konfigurieren Sie den Netzwerkadapter und öffnen Sie die Benutzeroberfläche des Sensors.</p>
  </div>

  <div class="strategy-card">
    <h3>2. Führen Sie die erste Demo aus</h3>
    <p>Beginnen Sie mit dem Projekt „Feldauswertung“, um zu verstehen, wie Erfassungsfelder funktionieren.</p>
  </div>

  <div class="strategy-card">
    <h3>3. Beispielprojekte erkunden</h3>
    <p>Setzen Sie fort mit Entfernungsschätzung, interaktiven Spielen oder audiobasierten LiDAR-Anwendungen.</p>
  </div>

  <div class="strategy-card">
    <h3>4. Fahren Sie mit den Code-Beispielen fort</h3>
    <p>Nutzen Sie die LiDAR-Code-Beispiele, um mit Python Geräteinformationen, Scandaten oder Ergebnisse der Feldauswertung auszulesen.</p>
  </div>

</div>
